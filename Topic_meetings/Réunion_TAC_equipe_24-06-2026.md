# Compte-rendu — points discutés

- **Base de données graphe** : j'ai travaillé avec Neo4j, mais l'équipe suggère de tester ArangoDB en alternative. → On va faire une comparaison entre les deux : garder Neo4j et tester ArangoDB en parallèle.

- **Milled** : demande d'ajouter une option pour saisir un concept existant. Le LLM génère le résultat, et l'utilisateur peut renseigner un concept déjà existant.

- **Kévin** : demande d'ajouter une option pour modifier les paramètres du modèle directement depuis l'interface.

- **Partenaires** : retours positifs sur l'application et sur les technologies utilisées.

- **Milled** : a fourni une API REST Opentheso pour accéder à des exemples de thésaurus à utiliser dans le service LLM. Il a précisé qu'Espadon ne contient pas assez de thésaurus pour des essais à grande échelle ; il a donc communiqué l'adresse d'un autre serveur, avec un contenu plus conséquent, ainsi qu'un serveur de test.
