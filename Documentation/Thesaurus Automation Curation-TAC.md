# Introduction

Dans cette page Notion, j'ai rassemblé tout ce que j'ai fait dans le projet TAC jusqu'à maintenant. L'objectif est de tout garder afin de rédiger, à la fin, un rapport et un article. On y trouve le détail des approches, des outils, etc. Le but du projet est de créer un outil, TAC, permettant de structurer et de générer des thésaurus, avec une interface web pour visualiser les résultats et un système à base de LLM pour assurer la génération.
